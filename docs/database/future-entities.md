# Proposed future entities (not yet implemented)

Derived from architecture §5/§2.6 and product spec §27. Each arrives **with its feature**, in its owner's schema, with tests. Listed here so features don't invent conflicting shapes.

| Schema (owner)  | Entities                                                                                                                                                                                        | Notes                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `identity`      | `auth_sessions` (if not fully IdP-managed), `devices`                                                                                                                                           | token hashes only                                                                                                              |
| `consent`       | `consent_receipts` versions, `privacy_requests` (export/delete)                                                                                                                                 | deletion must cascade to derived data (embeddings, caches)                                                                     |
| `memory`        | `memory_facts`, `memory_preferences`, `memory_events`, `memory_sources`, `memory_embeddings` (`vector(N)` + model/version columns, HNSW index via SQL), `memory_deletion_jobs`                  | user-scoped filter before vector search; provenance + confidence + sensitivity; no silent storage of inferred sensitive traits |
| `conversations` | `conversations`, `messages` (content ref, status, tool/action refs)                                                                                                                             | retention status per conversation                                                                                              |
| `goals`         | `goals`, `milestones`, `reminders` (rrule + timezone)                                                                                                                                           |                                                                                                                                |
| `tasks`         | `tasks` (state, version, provider_status, payment_status), `task_steps`, `task_events` (append-only), `task_participants`, `evidence`                                                           | state transitions only via `transitionTask`                                                                                    |
| `approvals`     | `approvals` (payload hash, max amount, expiry, assurance, status), `approval_decisions`                                                                                                         | single-use; material change → invalidated                                                                                      |
| `providers`     | `connected_accounts` (encrypted token ref), `provider_capabilities`, `external_operations` (unique idempotency key per provider/action), `external_refs`, `quotes`, `provider_inbox` (webhooks) |                                                                                                                                |
| `notifications` | `notifications` (dedupe key), `notification_preferences`                                                                                                                                        | delivery ≠ read                                                                                                                |
| `billing`       | `model_invocations` (architecture §2.6 fields; only reported metrics), `usage_ledger`, `subscriptions`, `entitlements`                                                                          |                                                                                                                                |
| `ops`           | `support_cases`, `support_assignments`, `feature_flags`                                                                                                                                         | staff access audited                                                                                                           |
