# Environment variable reference (canonical)

Each service reads **its own** `apps/<service>/.env` locally (`pnpm setup:env` copies every `.env.example`). Deployed environments inject variables from ECS task definitions and AWS Secrets Manager (see infra/terraform). Columns: **L** = needed for local dev, **P** = required in dev/staging/production, **S** = secret (Secrets Manager only).

## Shared

| Variable                                  | Services                       | L               | P             | S       | Notes                                                                             |
| ----------------------------------------- | ------------------------------ | --------------- | ------------- | ------- | --------------------------------------------------------------------------------- |

## ai-service (see apps/ai-service/.env.example for defaults)

- `KAREN_FEATURE_MEMORY_EXTRACTION_LIVE` — default `false`; **`true` refuses startup** (no live extractor exists; APP-1 not approved). Phase 03 serves `/internal/v1/memory/extract` with the deterministic mock extractor only (`is_mock: true`, cost 0).

`AI_SERVICE_PORT`, `OPENROUTER_BASE_URL` (`https://openrouter.ai/api/v1`), `OPENROUTER_API_KEY` (S, live only, ai-service only), `OPENROUTER_DATA_COLLECTION` (`deny` default; production refuses `allow`), `OPENROUTER_ZDR` (`true` default), `KAREN_AI_GATEWAY_MODE` (`mock` locally), `KAREN_MODEL_{ECONOMY,BALANCED,REASONING}` + `KAREN_MODEL_{ECONOMY,BALANCED,REASONING}_FALLBACK`, `KAREN_MODEL_{CODING,DOCUMENT_ANALYSIS,VOICE}` (optional pins; `VOICE` = spoken turns, ADR-0031, Claude Haiku 5.5 recommended per ADR-0034; leave all `KAREN_MODEL_*` empty for automatic least-cost routing, ADR-0026), `KAREN_MODEL_{VISION,EMBEDDING,RERANKING,AUDIO}`, `KAREN_MODEL_REGISTRY_PATH` (`config/model-registry.live.json` in live mode; entries must have `verified_at` from the `karen-ai-probe` SP-1 run), `KAREN_AI_MAX_OUTPUT_TOKENS`, `KAREN_AI_REQUEST_TIMEOUT_SECONDS`, `KAREN_AI_MAX_RETRIES`, `KAREN_AI_MAX_REQUEST_COST_USD`, `KAREN_AI_DAILY_BUDGET_USD`, `KAREN_AI_ALLOW_DIRECT_PROVIDER_FALLBACK` (must stay false), `KAREN_AI_BUDGET_STORE` (`memory` default in local/test; **`redis` required** in dev/staging/production), `REDIS_URL` **or** `REDIS_HOST`/`REDIS_PORT`/`REDIS_TLS`/`REDIS_AUTH_TOKEN` (S) (shared daily budget + replay cache, required when deployed), `KAREN_FEATURE_{VISION,EMBEDDING,RERANKING,AUDIO}_ENABLED`, `LANGFUSE_PUBLIC_KEY`/`LANGFUSE_SECRET_KEY` (S)/`LANGFUSE_HOST` (accepted; SDK not yet wired).
**Where to get real values:** OpenRouter dashboard → Keys (set a credit limit on the key); model slugs and prices from the public catalog `https://openrouter.ai/api/v1/models`, copied from the `Suggested env:` notes in `apps/ai-service/config/model-registry.live.json` after SP-1 verification (docs/gateway/openrouter.md). The former `AI_GATEWAY_BASE_URL`/`AI_GATEWAY_API_KEY` are no longer read (ADR-0025).

`LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` (S; from LiveKit Cloud project settings), `VOICE_AGENT_HEALTH_PORT`, `KAREN_FEATURE_AUDIO_ENABLED`, `KAREN_MODEL_AUDIO`, `KAREN_MODEL_REGISTRY_PATH`, `AI_SERVICE_URL`.

## temporal-worker / provider-worker

`TEMPORAL_ADDRESS` (`localhost:7233` locally; Temporal Cloud endpoint deployed), `TEMPORAL_NAMESPACE`, `TEMPORAL_TLS_ENABLED` (must be true in staging/production), `TEMPORAL_API_KEY` (S, Temporal Cloud), `TEMPORAL_WORKER_HEALTH_PORT` (4300), `TEMPORAL_MAX_CONCURRENT_ACTIVITIES`, `TEMPORAL_MAX_CONCURRENT_WORKFLOW_TASKS`; provider-worker also `PROVIDER_WORKER_PORT` (4200), Redis vars, `MOCK_PROVIDER_WEBHOOK_SECRET` (local/test/dev only; real providers get their own per-provider secrets).

## web / admin / mobile (PUBLIC — compiled into bundles)

`NEXT_PUBLIC_APP_ENV`, `NEXT_PUBLIC_API_BASE_URL`, `EXPO_PUBLIC_APP_ENV`, `EXPO_PUBLIC_API_BASE_URL`, `APP_VARIANT` (mobile build flavour). `pnpm check:env-public` fails CI if a public variable name looks secret.

## docker-compose (local only)

Postgres `karen` / `karen_local_only` — a fixed, local-only credential bound to 127.0.0.1.

## Web and admin BFF (server-only — never `NEXT_PUBLIC_*`)

| Variable                                 | App         | Local default           | Deployed                    | Notes                                                                                 |
| ---------------------------------------- | ----------- | ----------------------- | --------------------------- | ------------------------------------------------------------------------------------- |
| `API_INTERNAL_BASE_URL`                  | web, admin  | `http://localhost:4100` | API service address         | the BFF is the only thing that talks to the API                                       |
