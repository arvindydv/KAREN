## 2. Decisions the owner needs to make

| Decision                 | Recommended option                                                                               | Why                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| S-02 OTP lifetime        | Approve 10 minutes                                                                               | ASVS 6.5.5 L2 maximum; small change                                                                    |
| S-05 breached passwords  | Decide after confirming licence and size of the offline option; the range API is the faster path | Either closes 6.2.12; the choice is privacy (no outbound call) vs operational cost                     |
| S-06 consumer MFA        | Claim **L1** for consumers in Phase 01 and schedule passkeys as a tracked item                   | Passkeys on Expo need a device spike; blocking Phase 01 on them is not proportionate. Must be explicit |
| S-07 concurrent sessions | No hard cap; keep the visible device list; alert on unusual session counts                       | A cap mostly hurts users with several devices; visibility + revocation addresses the risk              |
| S-09 OTP storage         | Accept keyed HMAC as a documented deviation                                                      | A 6-digit code is brute-forceable through any hash; the secret key is the real control                 |
| S-10 mobile idle timeout | Accept as documented (AAL1, 30-day absolute, biometric lock)                                     | Consistent with NIST 800-63B-4 AAL1                                                                    |

These are recommendations, not decisions. Nothing changes until the owner records the decision.
