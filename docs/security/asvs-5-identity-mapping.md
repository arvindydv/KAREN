# OWASP ASVS 5.0 — requirement-level mapping for the Phase 01 identity platform

Source text: OWASP ASVS 5.0.0, `5.0/en/0x12`, `0x15`–`0x18` on GitHub (OWASP/ASVS), fetched 2026-11-20.
Requirement wording is summarised here; the official text is normative.

**Target:**

- **Consumer realm** (`/v1/auth`, `/v1/me`): ASVS **Level 2**.
- **Staff realm** (`/v1/staff`): Level 2, plus the L3 items marked below.

**Scope:**

- **Chapters:**
  - V6 Authentication.
  - V7 Session Management.
  - V8 Authorization.
  - V9 Self-contained Tokens.
  - V3 Web Frontend Security (web and admin BFFs).
- **Out of scope for Phase 01:**
  - V10 (OAuth/OIDC): no external IdP. ADR-0015 removed Cognito.
  - The remaining chapters, which are tracked by their owning phases.

**Evidence:**

- API code paths (#22–#28) are on `main` (merged 2026-11-20).
- Web, admin and mobile evidence is in M9 (#29), merged 2026-11-21 (`3bf9913`).
- "Test" names an automated test that exercises the control.

**Statuses:**

| Status       | Meaning                                                            |
| ------------ | ------------------------------------------------------------------ |
| MET          | Implemented and covered by an automated test or review             |
| MET (doc)    | A documentation requirement, satisfied by the cited document       |
| PARTIAL      | Implemented in part; the remaining gap is stated                   |
| GAP          | Not met; owner and next step are stated                            |
| N/A          | The feature does not exist in Phase 01                             |
| NOT VERIFIED | Implemented, but not validated where it matters (devices, staging) |

This is a self-assessment by the implementers. It is **not** an independent ASVS verification. Gate 01 needs an independent review.
