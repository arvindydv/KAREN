# Runbook: kill switches and incident containment

| Situation                                                                          | Action                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unapproved/duplicate execution suspected                                           | Set `KAREN_EXECUTION_PAUSED=true` for the api (policy denies all new executions) **and provider-worker** (refuses every side-effecting provider call before dispatch, including already-approved workflows, which end `ESCALATED` with nothing executed; status reconciliation keeps working). Scaling provider-worker to 0 is a last resort: it also stops reconciliation. Committed external obligations continue to be tracked. |
| AI cost spike / abuse                                                              | Lower `KAREN_AI_DAILY_BUDGET_USD`/`KAREN_AI_MAX_REQUEST_COST_USD`; use Vercel gateway budgets as hard backstop; disable tiers via feature flags.                                                                                                                                                                                                                                                                                   |
| Gateway outage (see `model-gateway-outage.md`)                                     | Typed errors surface to users; action plane unaffected. Do not enable direct providers without approval.                                                                                                                                                                                                                                                                                                                           |
| Compromised secret                                                                 | Rotate in Secrets Manager; redeploy affected services; for `INTERNAL_SERVICE_HMAC_SECRET` rotate verifier-first. Review audit events by `request_id`.                                                                                                                                                                                                                                                                              |
| Provider misbehaviour (see `provider-outage.md`)                                   | Remove the adapter from the registry (deploy) — workflows will fail with CAPABILITY_UNAVAILABLE and escalate; reconcile open operations via status.                                                                                                                                                                                                                                                                                |
| Per-provider pause flags and an admin UI toggle are planned (product spec SEC-08). |
